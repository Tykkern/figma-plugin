# Design from Claude — Figma Plugin

A local Figma plugin that imports designs generated by Claude directly as
editable frames: real text nodes, rectangles, vector icons — no raster images.

## Quick start

1. In Figma Desktop: **Plugins → Development → Import plugin from manifest…**
2. Select `manifest.json` from this folder.
3. Export `outfitfly-figma.json` from your prototype (or generate one with Claude — see `CLAUDE.md`).
4. Run the plugin, load the JSON, click **Import to Figma**.

## JSON format

See [`CLAUDE.md`](CLAUDE.md) for the complete schema and examples.
Use `CLAUDE.md` as the system prompt / project instructions when asking Claude
to generate new designs in this format.

## What gets created

| JSON layer type | Figma node |
|-----------------|-----------|
| `rect` | Rectangle with fill / stroke / corner-radius |
| `text` | Editable Text node with font, size, color |
| `svg` | Vector group parsed from SVG markup |

Frames are placed in a grid: themes as rows, screens as columns.
