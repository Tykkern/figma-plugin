# HTML → Figma (анимации)

Плагин Figma переносит HTML-страницу в редактируемые слои и собирает прототип из её анимаций, наведений и кликов. Настраивать его под проект не нужно: на вход идёт сам HTML-файл, JSON под каждый проект больше не готовится.

Захват вёрстки взят из [open-htmltofigma](https://github.com/kevicebryan/open-htmltofigma) (MIT, лицензия в `LICENSE`). Анимации, клик-состояния, ссылки и спецификация написаны поверх него.

## Установка

1. `npm install`, затем `npm run build` (собирает `code.js` из `code.ts`).
2. Figma desktop: Plugins → Development → Import plugin from manifest → `manifest.json`.

## Как пользоваться

1. Выберите HTML-файл. Если экранов несколько, выберите их все или папку целиком: каждый файл станет отдельным экраном, ссылки между ними станут переходами.
2. Если табы, переключатели или аккордеоны на странице работают на JavaScript, включите «Выполнять скрипты страницы». Для своих файлов это безопасно. Без этой опции переносятся только клики, которым скрипты не нужны: `<details>`, `<label>`, чекбоксы.
3. Нажмите «Импортировать в Figma».

На холсте появятся:

- экран страницы (фрейм шириной окна, высотой во всю страницу);
- рамка «Компоненты · анимации и состояния» с наборами вариантов;
- фрейм «Спецификация анимаций»: что попало в прототип, а что описано только текстом.

## Что и как переносится

| На странице | В Figma |
| --- | --- |
| `:hover` с `transition` | Набор «Обычное / Наведение», While hovering → Smart Animate с длительностью и кривой из CSS |
| `@keyframes`, бесконечные | Кадры-варианты, After delay → Smart Animate по кругу; `alternate` идёт туда и обратно |
| `@keyframes`, один раз (появление) | Вариант «Статика» (финальный вид на холсте) → первый кадр → проигрывание при открытии экрана |
| Клик, меняющий часть страницы | Варианты «Обычное / Клик N», On click → Change to. Если повторный клик возвращает состояние, переход назад тоже есть |
| Текст, меняющийся по клику внутри другого компонента (цены Месяц/Год) | Оверрайд текста на инстансе, наведение у карточки сохраняется |
| `href="#id"` | Scroll to нужного слоя |
| `href="page.html"` | Navigate на экран этого файла |
| `http(s):`, `mailto:`, `tel:` | Open link |
| `position: fixed` | Слой закреплён при прокрутке |
| `::before`, `::after`, включая их анимации | Отдельные слои |
| SVG с фильтрами (`feTurbulence` и т.п.) | Растровый слой «svg (растр)» |

Только в спецификации, без прототипа:

- анимации на JavaScript (requestAnimationFrame, таймеры);
- реакции на курсор и на прокрутку (параллакс, свечение за мышью);
- `position: sticky` (в Figma «Sticky» включается вручную);
- SVG-анимации SMIL, видео и canvas (в Figma один кадр);
- анимации, привязанные к прокрутке (`animation-timeline`);
- клики, которые меняют страницу целиком.

## Ограничения

- Кривые `steps()` и `linear(…)` переносятся как линейные.
- Шаг Smart Animate длиннее 10 секунд разбивается на несколько кадров. Для равномерного движения (бегущая строка) это точно.
- Нестандартный `scale` по одной оси и наклон переносятся рамкой, а не трансформацией.
- Не больше 200 анимированных элементов и 24 кликабельных на страницу. Остальное попадает в спецификацию.
- Делегированные обработчики (один `click` на весь список) клик-состояния не дают.
- Если наведение и клик приходятся на один элемент, в прототипе остаётся клик.

## Проверки

```bash
npm run build
python test/run.py
```

`test/run.py` прогоняет три набора:

- `test/check.html`: статичный захват форка;
- `test/motion-check.html`: анимации, наведение и клики на `examples/motion.html`;
- `test/main-check.mjs`: главный поток на подменённом API Figma. Он проверяет то, что отклонила бы сама Figma: Change to вне набора вариантов, Scroll to на другой экран, задержки меньше 1 мс.

Для запуска нужны Playwright для Python (`pip install playwright` и `playwright install chromium`) и Node 18+.
